# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to security@heossi.com. Do not open a
public issue, and do not include exploit details in a public discussion.

Include the affected component (MCP server, native CLI, portal), version, and a
minimal reproduction. We will acknowledge receipt and keep you informed of the
remediation timeline.

## Scope

In scope: the MCP server distributed as `@heossihq/saar-mcp`, the licence
verification path, and the portal at https://portal.saar.heossi.com.

Out of scope: findings that require a compromised host, or that depend on
disabling the licence verifier.
