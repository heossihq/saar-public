# Contributing

This repository is the public integration surface for a proprietary engine, so
the codec source is not here and pull requests against a compressor are not
accepted.

Useful contributions:

- corrections to the documentation, configuration templates, or examples;
- reproducible bug reports against the MCP server with the exact versions of
  `@heossihq/saar-mcp`, Node.js and `saar_native`;
- client-specific configuration for MCP clients not yet covered in `mcp/configs`.

For anything security-sensitive, follow [SECURITY.md](./SECURITY.md) instead.
